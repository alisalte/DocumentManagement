# گردش کار

1. سند ایجاد می‌شود (بدون شماره).
2. کاربر مجاز «ثبت در اندیکاتور» را می‌زند.
3. اگر سند شماره دارد ← پایان (اقدام در دسترس نیست).
4. اگر نوع سند الگو ندارد ← سؤال Q3.
5. سیستم شماره بعدی شمارنده را به‌صورت اتمیک تخصیص می‌دهد.
6. شماره، کاربر و زمان ثبت ذخیره و در لاگ فعالیت ثبت می‌شود.
7. اگر بعداً سند حذف شود ← شماره سوخت می‌شود و دوباره استفاده نمی‌شود.
