# موارد کاربرد

## UC-1 تعریف الگو
مدیر ← تنظیمات نوع سند ← تعریف الگو ← پیش‌نمایش شماره نمونه ← ذخیره.

## UC-2 ثبت سند در اندیکاتور
کاربر مجاز ← صفحه سند بدون شماره ← «ثبت در اندیکاتور» ← تأیید ← شماره تخصیص و نمایش داده می‌شود.
- جایگزین: نوع سند الگو ندارد ← سؤال Q3
- جایگزین: سند قبلاً شماره دارد ← اقدام نمایش داده نمی‌شود.
- جایگزین: کاربر مجوز ندارد ← اقدام نمایش داده نمی‌شود و API خطای دسترسی می‌دهد.

## UC-3 جستجو با شماره
کاربر ← جستجو یا فیلتر شماره اندیکاتور ← سند مربوط.

## UC-4 شماره‌دهی اسناد موجود
سیستم یک‌بار اسناد بدون شماره را به‌ترتیب تاریخ ایجاد شماره‌گذاری می‌کند.
