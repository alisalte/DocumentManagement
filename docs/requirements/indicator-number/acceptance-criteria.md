# معیارهای پذیرش

- **AC-1** Given سندی بدون شماره و کاربری با مجوز ثبت، When «ثبت در اندیکاتور» را می‌زند، Then سند شماره بعدی طبق الگوی نوع سندش را می‌گیرد.
- **AC-2** Given سندی با شماره، When هر کاربری (از جمله مدیر) بخواهد شماره را تغییر دهد، Then سیستم رد می‌کند.
- **AC-3** Given دو ثبت هم‌زمان روی دو سند با شمارنده مشترک، Then دو شماره متفاوت و متوالی تخصیص می‌یابد.
- **AC-4** Given سند شماره‌دار حذف شود، When سند بعدی ثبت شود، Then شماره حذف‌شده دوباره استفاده نمی‌شود.
- **AC-5** Given کاربر بدون مجوز، Then اقدام ثبت را نمی‌بیند و API آن را رد می‌کند.
- **AC-6** Given اسناد موجود پیش از این قابلیت، After استقرار، Then همه به‌ترتیب تاریخ ایجاد شماره دارند.
- **AC-7** Given یک شماره اندیکاتور، When در جستجو وارد شود، Then همان سند پیدا می‌شود.
- **AC-8** Given ثبت شماره، Then یک رکورد در لاگ فعالیت با کاربر و شماره ایجاد می‌شود.
- **AC-9** Given نوع سندی بدون الگوی اختصاصی، When سندش ثبت شود، Then شماره طبق الگوی پیش‌فرض و با شمارنده همان نوع سند ساخته می‌شود.
- **AC-10** Given مدیر الگوی یک نوع سند را بعد از چند ثبت تغییر دهد، Then شماره‌های قبلی تغییر نمی‌کنند و شماره بعدی با الگوی جدید و ادامه شمارنده ساخته می‌شود.
- **AC-11** Given سند شماره‌دار، When چاپ یا پیش‌نمایش شود، Then شماره روی صفحات دیده می‌شود.
- **AC-12** Given اولین ثبت در سال مالی جدید برای یک نوع سند، Then شماره ترتیبی از ۱ شروع می‌شود.
