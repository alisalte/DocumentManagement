# محدوده

## داخل محدوده
- تعریف الگو برای هر نوع سند
- ثبت دستی شماره توسط کاربر مجاز
- نمایش و جستجوی شماره
- شماره‌دهی یک‌باره اسناد موجود و اسناد import‌شده
- لاگ فعالیت
- الگوی پیش‌فرض کلی
- مجوز جدید «ثبت در اندیکاتور»
- درج شماره روی چاپ و پیش‌نمایش

## خارج از محدوده
- ویرایش یا ابطال شماره
- رزرو شماره پیش از ایجاد سند
- دفتر اندیکاتور وارده/صادره (مکاتبات)

## بهبودهای آینده
- گزارش و خروجی دفتر اندیکاتور به‌تفکیک سال
- نمایش شماره در اپ موبایل
