# قواعد کسب‌وکار

| کد | قاعده | منبع |
|---|---|---|
| BR-1 | الگوی شماره برای هر نوع سند قابل تنظیم است. | تأیید کاربر |
| BR-2 | شماره فقط با اقدام دستی کاربر مجاز تخصیص می‌یابد. | تأیید کاربر |
| BR-3 | هر سند حداکثر یک شماره اندیکاتور دارد. | تأیید کاربر (A1) |
| BR-4 | شماره پس از تخصیص تغییرناپذیر است. | تأیید کاربر |
| BR-5 | با حذف سند، شماره‌اش «سوخت» می‌شود و هرگز دوباره استفاده نمی‌شود؛ فاصله در شماره‌ها مجاز است. | تأیید کاربر |
| BR-6 | اسناد موجود و import‌شده به‌ترتیب تاریخ ایجاد شماره خودکار می‌گیرند. | تأیید کاربر |
| BR-7 | شمارنده به‌ازای هر «نوع سند + سال مالی» جداست و در هر سال مالی برای هر نوع سند از ۱ شروع می‌شود. | تأیید کاربر |
| BR-8 | الگو از این اجزا ساخته می‌شود: پیشوند متنی، کد نوع سند، سال مالی، کد دسته‌بندی، شماره ترتیبی با طول ثابت (صفر در ابتدا)، جداکننده. هر الگو باید شماره ترتیبی داشته باشد. | تأیید کاربر |
| BR-9 | کد دسته‌بندی فقط در متن شماره می‌آید و شمارنده را جدا نمی‌کند. | نتیجه BR-7 |
| BR-10 | یک الگوی پیش‌فرض کلی وجود دارد که برای هر نوع سند بدون الگوی اختصاصی (در ثبت دستی و شماره‌دهی اسناد قدیمی) به کار می‌رود. شمارنده باز هم برای هر نوع سند و سال جداست. | تأیید کاربر |
| BR-11 | مدیر می‌تواند الگو را در هر زمان تغییر دهد؛ تغییر فقط روی شماره‌های بعدی اثر دارد و شمارنده ادامه پیدا می‌کند. | تأیید کاربر |
| BR-12 | ثبت در اندیکاتور یک مجوز مستقل است که مدیر به نقش‌ها می‌دهد. | تأیید کاربر |
| BR-13 | چون شمارنده هر سال از ۱ شروع می‌شود، هر الگو باید سال مالی را داشته باشد؛ وگرنه شماره سال‌های مختلف تکراری می‌شود. | تأیید کاربر |
| BR-14 | متن کامل شماره اندیکاتور در کل سیستم یکتاست. | NFR یکتایی |
| BR-15 | هر نوع سند یک «کد نوع سند» کوتاه و یکتا دارد. الگوی پیش‌فرض کلی باید کد نوع سند را داشته باشد. | تأیید کاربر (Q8) |
| BR-16 | ذخیره الگویی که بتواند متن تکراری با الگوی نوع سند دیگری بسازد رد می‌شود (برای مثال، الگوی اختصاصی بدون کد نوع سند و با پیشوندی که نوع دیگری هم دارد). | تأیید کاربر (Q8) |
| BR-17 | سند متعلق به سال مالی بسته و سند رسمی (Record) هم قابل ثبت در اندیکاتورند. | تأیید کاربر (AQ2، AQ3) |
| BR-18 | شماره‌دهی اسناد موجود با اقدام مدیر و بعد از تنظیم الگوها انجام می‌شود و اسناد حذف‌شده را هم شامل می‌شود. | تأیید کاربر (AQ4، AQ5) |
| BR-19 | اسناد import‌شده بعد از آخرین شماره صادرشده سال مالی خود شماره می‌گیرند؛ ترتیب تاریخ فقط داخل هر اجرای import تضمین می‌شود. | ریسک پذیرفته‌شده |
