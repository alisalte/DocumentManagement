# تحلیل فاصله

| نیاز | وضعیت فعلی | کار لازم |
|---|---|---|
| کد نوع سند (BR-15) | **هست:** `DocumentType.Code` یکتا و تغییرناپذیر است | فقط استفاده شود؛ نیازی به کد موقت T01/T02 نیست (سؤال AQ1) |
| الگوی اختصاصی هر نوع | نیست | فیلد `IndicatorPattern` در `DocumentTypeSettings` |
| الگوی پیش‌فرض کلی | جدول تنظیمات کلی وجود ندارد | جدول تک‌ردیفی جدید در ماژول DocumentTypes |
| پارس، اعتبارسنجی و پیش‌نمایش الگو | نیست | کلاس `IndicatorPattern` (قابل تست واحد) |
| شمارنده هر نوع سند و سال | نیست | جدول `indicator_counters` با افزایش اتمیک |
| شماره روی سند | نیست | ستون‌های جدید روی `documents` و ایندکس یکتا |
| مجوز ثبت | نیست | `DOCUMENT_REGISTER_INDICATOR` |
| ثبت دستی | نیست | Command و endpoint جدید |
| شماره‌دهی اسناد موجود | نیست | Seeder یک‌باره |
| شماره‌دهی import | نیست | تخصیص خودکار در `ImportEngine` |
| لاگ فعالیت | زیرساخت هست | Action جدید و متن فارسی |
| جستجو | فیلد نیست | فیلتر Postgres و فیلد keyword در OpenSearch (نیاز به بازسازی ایندکس) |
| درج روی چاپ و پیش‌نمایش | فقط واترمارک | درج شماره در گوشه صفحه، در همان مرحله واترمارک |
| رابط کاربری | — | صفحه سند، فهرست، ویرایشگر نوع سند، تنظیم الگوی پیش‌فرض |
