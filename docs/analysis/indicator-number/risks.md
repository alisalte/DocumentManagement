# ریسک‌ها

| ریسک | اثر | کاهش |
|---|---|---|
| Backfill با الگوی نهایی‌نشده اجرا شود | هزاران شماره تغییرناپذیر با قالب نامطلوب | Backfill خودکار نیست و مدیر بعد از تنظیم الگوها آن را اجرا می‌کند. پنجره تأیید هم تغییرناپذیر بودن شماره‌ها را یادآوری می‌کند (AQ5). |
| ترتیب اسناد import‌شده | اسنادی که بعداً برای یک سال قدیمی import می‌شوند، شماره‌شان بعد از شماره‌های قبلی آن سال می‌آید، نه به ترتیب واقعی تاریخ | فقط داخل هر اجرای import ترتیب تاریخ حفظ می‌شود. در requirements مستند شود. |
| کد طولانی نوع سند | کد تا ۶۴ کاراکتر است و شماره طولانی می‌شود | فقط هشدار در پیش‌نمایش. کد نوع سند تغییرناپذیر است. |
| تداخل الگوها | شماره تکراری | بررسی هنگام ذخیره و ایندکس یکتا |
| تغییر mapping OpenSearch | تا بازسازی ایندکس، جستجوی متنی شماره کار نمی‌کند | فیلتر دقیق Postgres از روز اول کار می‌کند. بازسازی در راهنمای استقرار ذکر شود. |
| گلوگاه هم‌زمانی شمارنده | ثبت‌های هم‌زمان یک نوع سند پشت هم اجرا می‌شوند | قفل فقط به اندازه یک تراکنش کوتاه طول می‌کشد و برای حجم دبیرخانه کافی است. |
| `{CAT}` و جابه‌جایی سند | بعد از انتقال سند به دسته دیگر، شماره کد دسته قبلی را نشان می‌دهد | رفتار درست است (شماره تغییرناپذیر است)، ولی در راهنما توضیح داده شود. |
