# اثر روی رابط کاربری (frontend)

| صفحه | تغییر |
|---|---|
| `DocumentPage` | نمایش شماره و تاریخ و کاربر ثبت در بخش مشخصات. اگر سند شماره ندارد و کاربر مجوز دارد، دکمه «ثبت در اندیکاتور» با یک پنجره تأیید که می‌گوید شماره قابل تغییر نیست. |
| `BrowsePage` و `SearchPage` | ستون یا برچسب شماره، و امکان جستجو با شماره. |
| `RecycleBinPage` | نمایش شماره سند حذف‌شده. |
| `admin/DocumentTypeEditorPage` | فیلد «الگوی شماره اندیکاتور» (خالی یعنی پیش‌فرض)، راهنمای توکن‌ها، و پیش‌نمایش زنده شماره نمونه. |
| `admin/DocumentTypesPage` | بخش «الگوی پیش‌فرض شماره اندیکاتور» با پیش‌نمایش، و دکمه «شماره‌دهی اسناد موجود» با تعداد اسناد بدون شماره و یک پنجره تأیید که می‌گوید شماره‌ها تغییرناپذیرند. |
| `admin/RolesPage` | نام فارسی مجوز جدید در `adminStrings.ts`. |
| `admin/auditStrings.ts` و `auditDescribe.ts` | جمله ساده برای ثبت شماره (دستی، import یا خودکار) و تغییر الگو. |
| `DocumentViewer` | شماره روی تصویر صفحه درج می‌شود و تغییری در فرانت لازم نیست. |
| `helpGuideContent.ts` | یک بخش راهنما. |

اپ موبایل در این مرحله خارج از محدوده است (فقط فیلد جدید در API).
